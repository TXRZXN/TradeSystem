# TradeSystem

TradeSystem is a collection of trading strategies for TradingView, developed by TXRZXN.  
This project includes Pine Script strategies for various types such as Mean Reversion, DCA, Trend Following, and more.

## Project Structure

- **DCA/**  
  DCA strategies such as Momentum and Volatility Base

- **MeanReversion/**  
  Mean Reversion strategies such as ATR, Donchian, Stdev

- **Trend Follow/**  
  Trend following strategies such as ATR, Bollinger Bands, Darvas Box, Pivot Breakout

- **Other/**  
  Other scripts such as Display Strategy

## How to Use

1. Open the desired `.pine` file in the TradingView Pine Editor
2. Adjust the parameters as needed
3. Click "Add to Chart" to apply the strategy
